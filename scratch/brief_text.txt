PROJECT BRIEFMarkazu Umar School Management System (MSSMS)
Project Owner
Elmuaz Technologies LTD
Client
Markazu Umar bn Khattab Tahfizul Qur'an & Islamic Studies SchoolKano, Nigeria.
Project Goal
Develop a modern enterprise-grade School Management System specifically for Markazu Umar School.This is NOT a clone of MyEcole, but MyEcole will serve as the primary workflow and UI reference.The system should be faster, more secure, more scalable, easier to maintain, tailored for an Islamiyya/Tahfiz school, and commercial quality.
Important
This project is NOT multi-tenant. It is designed for one school only, but should use a clean, modular architecture.
Expected Users
Students: 2,000+Teachers: 70+Parents: 3,000+Administrators: 10+Concurrent users expected to grow over time.
Technology Stack
Frontend: Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, React Hook Form, Zod, TanStack QueryBackend: NestJS, TypeScript, Prisma ORMDatabase: PostgreSQLAuthentication: JWT, Refresh Tokens, RBACDeployment: Hostinger VPS (KVM 1 initially), Ubuntu LTS, Nginx, Let's Encrypt SSL
Development Principles
Clean ArchitectureSOLID PrinciplesFeature-based structureReusable componentsScalable, maintainable codeEnterprise coding standardsProper documentation
Reference Software
MyEcole School Management System is the reference for workflow and UI. Preserve familiar navigation while improving architecture, security, performance, and UI quality.
School Characteristics
Islamiyya school requiring modules for Qur'an Memorization, Hifz, Sabki, Manzil, Tajweed, Arabic, Fiqh, Hadith, Aqeedah, Seerah, and Islamic Behaviour.
Payment Module
Version 1 will NOT include Finance, Student Wallet, Payments, Invoices, or Revenue because the school is free. The architecture should still support adding Finance later.
